# Triage labels

Confirmed by the maintainer on 2026-10-06. Local conventions only; remote label existence is unverified.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting evaluation |
| needs-info | needs-info | Awaiting information |
| ready-for-agent | ready-for-agent | Fully specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

Use the tracker label corresponding to each role. The locally installed triage skill is a maintenance aid, not an addition to the pack's 18 runtime skills.
